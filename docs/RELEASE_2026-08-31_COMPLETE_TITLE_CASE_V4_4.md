# StatusDeck v4.4 — Complete Title Case Naming Consistency

This release corrects the incomplete v4.2/v4.3 naming sweep.

## What changed
- Dynamic delivery states are forced through a shared Title Case formatter (At Risk, Watch Closely, On Track, etc.).
- Executive Summary, Executive Pulse and Management Commentary dynamic labels use Title Case.
- Static UI controls and section labels visible in Sprint and Project / Program reports were reviewed and corrected.
- Buttons/toggles such as Reporting Scheduler, Story Points, Remaining Effort, Live Events, Full Table and Open Core Gaps in Jira use Title Case.
- Normal explanatory prose remains sentence case.
- Calculations, Jira queries, AC/traceability logic, exports, scheduler behavior and Assistant logic are unchanged.
