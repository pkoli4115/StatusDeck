# StatusDeck v4 — Executive Gloss Polish

Date: 2026-08-24

This release builds on the accepted v3 baseline and changes presentation only. It does not change Jira calculations, report data, project/program commentary behavior, Custom Jira Insights scoping, exports, scheduler, Confluence publishing, or Assistant logic.

## Sprint report presentation changes

- Richer sprint identity banner with subtle layered depth.
- Executive Pulse upgraded with clearer RAG, larger high-signal metrics, and a more polished progress treatment.
- Executive Summary upgraded to a premium executive hero surface with stronger typography and higher contrast KPI tiles.
- Management Commentary upgraded with larger at-a-glance metrics, clearer callouts, stronger risk/action/outlook panels, and improved spacing.
- Responsive handling retained for narrower Jira app widths.
- Print/export safety override removes blur-dependent effects during print capture.

## Preserved v3 behavior

- Project / Program executive commentary layout.
- Sprint + Project Custom Jira Insights inheritance into Project / Program reports.
- Sprint-only vs Project-only vs Sprint + Project visibility semantics.
- Editable commentary Save draft / Publish / Restore generated workflow.
- Read-only Present Mode.
