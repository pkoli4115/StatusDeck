# StatusDeck v4.2 — UI Naming Consistency

## Purpose
Apply a consistent presentation naming standard across StatusDeck after review feedback.

## Naming standard
- Visible product labels, headings, cards, tabs, section names, table headers and export headings use **Title Case**.
- Normal explanatory sentences remain sentence case.
- Code identifiers and parser aliases are unchanged.

## Coverage
The consistency sweep covers:
- Sprint Status Report UI
- Project / Program Report UI
- Executive Summary and Management Commentary
- report section selector
- metric cards and tables
- Configuration / Reporting Scheduler / Custom Jira Insights labels
- PowerPoint export
- PDF export
- Confluence output

Examples:
- Delivery progress → Delivery Progress
- Sprint report → Sprint Report
- Sprint scope history → Sprint Scope History
- Team workload → Team Workload
- Traceability & quality evidence → Traceability & Quality Evidence
- Project health at a glance → Project Health at a Glance

No data calculations, report logic, Jira queries, Assistant behavior, permissions, or manifest scopes are changed by this release.
