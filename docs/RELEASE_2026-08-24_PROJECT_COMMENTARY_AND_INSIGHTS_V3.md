# StatusDeck — Project Commentary & Shared Custom Jira Insights v3

- Increased Executive Commentary typography for faster stakeholder scanning.
- Applied the same at-a-glance commentary pattern to Project / Program reports.
- Project commentary now presents Project Status, Mean Completion, Open Work, Teams at Risk, Overdue, Defects, Blocked/Impeded, Key Risks, Recommended Actions, and Release/Milestone Outlook.
- Project commentary editing is collapsed behind Edit commentary; Save draft / Publish / Restore generated are preserved.
- Custom Jira Insight definitions configured on an individual board with **Sprint + Project** or **Project only** are inherited by the Project / Program report when All Scrum boards is selected.
- Sprint-only definitions remain sprint-only.
